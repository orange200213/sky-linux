# sky-linux M4 — mainline Linux on the Redmi 12 5G (SM4450)

First public image. It boots mainline **Linux 7.3** on the Xiaomi Redmi 12 5G
(`sky`, Qualcomm SM4450 / Snapdragon 4 Gen 2) with our own device tree, and
gives you a usable Linux system over the USB cable.

## What works

* **M0** freestanding boot shim flashed as `boot_a` (no Android boot image, our
  own DTB)
* **M1** mainline kernel boots to user space; framebuffer console on the
  display ABL left behind
* **M2** USB gadget: CDC ACM serial console (`/dev/ttyACM0` ↔ `/dev/ttyGS0`)
* **M3** USB networking (CDC NCM, `192.168.7.1/24` + DHCP) and **SSH**
* **M4** UFS: 6 LUNs enumerated, `userdata` (ext4, ~108 GiB) mounted read/write,
  persistent kernel log at `/mnt/log/dmesg-last.txt`

## What does not work yet

Display driver (DPU/DSI/panel — framebuffer console only), touch, Wi-Fi/BT,
audio, camera. Android will not boot while this image is in `boot_a`.

## Requirements

Unlocked bootloader, active slot `a`, and the stock `boot.img` at hand for
recovery.

## Install

```bash
sha256sum sky-linux-m4-boot-a.img    # must match SHA256SUMS
fastboot flash boot_a sky-linux-m4-boot-a.img
fastboot reboot
```

Recovery:

```bash
fastboot flash boot_a /path/to/stock/boot.img
```

## Use

```bash
# serial console (root shell)
sudo picocom -b 115200 /dev/ttyACM0

# or ssh over USB networking
sudo ip addr add 192.168.7.20/24 dev <enx… interface>
ssh root@192.168.7.1        # password: sky
```

Full instructions, troubleshooting table and hardware notes:
`docs/install-and-usage.md`, `docs/hardware.md`, `docs/debugging.md`.

## Notes

* Only `boot_a` is written by this image. Nothing else on the phone is touched.
* The image contains the ROCKNIX SM4450 patch set (GPL-2.0) plus two local
  patches documented in `kernel/README.md`.
* Everything is reproducible from the repository — see `docs/m0-boot-shim.md`,
  `kernel/README.md`, `dts/README.md`, `initramfs/README.md`.
